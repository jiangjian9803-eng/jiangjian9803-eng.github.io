# Jian Jiang — AI & Software Portfolio

A responsive Next.js portfolio highlighting AI agents, machine learning, data systems, and software engineering.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
```

The static GitHub Pages output is generated in `out/`.

Public URL after deployment: `https://jiangjian9803-eng.github.io`
